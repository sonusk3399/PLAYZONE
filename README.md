# 🎮 PlayZone – Mini Games Collection

Welcome to **PlayZone**, a collection of fun and interactive browser-based games built using HTML, CSS, and JavaScript.

Play games, challenge yourself, and enjoy!

## 🎯 Games Included

### 1. Tic Tac Toe ❌⭕
- Two-player gameplay.
- Interactive 3×3 game board.
- Automatic winner detection.
- Draw detection.
- New Game and Reset Game options.

### 2. Rock Paper Scissors ✊✋✌️
- Play against the computer.
- Random computer moves.
- Automatic winner detection.
- Live score tracking.
- Draw detection.
- Reset Game functionality.

## 🛠️ Technologies Used

- HTML5

## ✨ Features

- Simple and user-friendly interface.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Select your favorite game.
5. Start playing!

## 🎮 Game Rules

**Tic Tac Toe**
- Two players take turns placing X and O.
- The first player to get three marks in a row, column, or diagonal wins.
- If all boxes are filled without a winner, it's a draw.

**Rock Paper Scissors**
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Same choices result in a draw.
